Host build is Meson-only.

Required toolchain:
    Clang 18+ or GCC 13+
    C17 and C++26

Fedora setup:
    sudo dnf install clang lld ninja-build meson tinyxml-devel gtest-devel

Configure and build:
    CXX=clang++ CC=clang meson setup builddir --wipe -Dc_std=c17 -Dcpp_std=c++26
    meson compile -C builddir

Optional unit tests:
    CXX=clang++ CC=clang meson setup builddir --wipe -Dc_std=c17 -Dcpp_std=c++26 -Dtests=true
    meson compile -C builddir
    meson test -C builddir

Notes:
    - tinyalsa-devel is not shipped by Fedora, so this project uses a host-only compatibility
      shim under compat/include/tinyalsa/asoundlib.h.
    - The legacy host build path has been removed; Meson is the only supported build
      entry point for this port.
